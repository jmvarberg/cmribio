# Example bulk RNAseq counts matrix

A gene x sample counts matrix as generated by nf-core/rnaseq with
star_rsem

## Usage

``` r
demo_counts
```

## Format

A data frame with 12 columns/samples and 78,317 rows/genes/features:

## Source

Generated in `data-raw/demo_counts.R`.

## Details

Used for demo purposes of '\_targets_bulkRNA_DEseq2.R' demo pipeline for
bulk RNAseq analysis. Generated using code in: `data-raw/demo_counts.R`.
